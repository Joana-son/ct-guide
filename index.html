새 카드뉴스 추가하는 법

1. ct-guide 안에 영문 소문자 폴더를 만듭니다 (예: chest-ct)
2. 그 안에 카드뉴스 파일을 index.html 이라는 이름으로 넣습니다
3. GitHub Desktop에서 커밋 후 Push 하면 1~2분 뒤 주소가 살아납니다
4. 주소는 https://joana-son.github.io/ct-guide/폴더이름/ 형태가 됩니다
기존 주소는 바뀌지 않으니 인쇄한 QR코드는 계속 사용할 수 있습니다.
